# Scripts for R_ψ(5,5) ≤ 16 Verification

This directory contains Python scripts for generating and testing vibrational Ramsey graphs.

## Scripts

### generate_graphs.py
Generates vibrational graphs with frequency assignments for testing.

```bash
python scripts/generate_graphs.py
```

### test_coloring.py
Tests coloring unsatisfiability for R_ψ(5,5) ≤ 16.

```bash
python scripts/test_coloring.py
```

### vibrational_model_plot.py
Analyzes and plots resonance patterns in vibrational graphs.

```bash
python scripts/vibrational_model_plot.py
```

## Requirements

- Python 3.8+
- numpy (for graph generation and analysis)
