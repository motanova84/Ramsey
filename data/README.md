# Data Files for R_ψ(5,5) ≤ 16 Proof

This directory contains verification data and models for the formal proof of R_ψ(5,5) ≤ 16.

## Files

- **rpsi_vibration_model.json**: Vibrational Ramsey model parameters
- **coloring_sat_r55.cnf**: SAT formula for coloring verification
- **proof_unsat_z3.log**: Z3 solver verification log
- **verified_bound_R55.json**: Certificate of verified bound
- **graph_r55_n16.json**: Example vibrational graph with 16 vertices (generated)

## Parameters

- Base frequency: f₀ = 141.7001 Hz
- Resonance threshold: ε = 0.001
- Clique sizes: r = 5, s = 5
- Bound: n = 16
