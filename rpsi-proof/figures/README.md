## Concepts Illustrated

### Circular Distance

The key insight of vibrational Ramsey numbers is the use of circular distance on a frequency circle:

```
d(ωᵢ, ωⱼ) = min(|ωᵢ - ωⱼ|, f₀ - |ωᵢ - ωⱼ|)
```

This creates a fundamentally different structure than linear Ramsey numbers.

### Resonance Zones

Each vertex ωᵢ has a resonance zone:
```
Resonant(ωᵢ) = {ω : d(ω, ωᵢ) ≤ ε}
```

Shown as light blue regions in the visualization.

### Edge Coloring

- **Blue Edge**: d(ωᵢ, ωⱼ) ≤ ε (resonant, frequencies close)
- **Red Edge**: d(ωᵢ, ωⱼ) > ε (non-resonant, frequencies far)

### Why K₁₆ Cannot Avoid Monochromatic K₅

The visualization demonstrates why:

1. **Frequency Density**: 16 vertices on a circle of length 141.7001 Hz with grid resolution 128
2. **Resonance Constraint**: ε = 0.037 creates overlapping resonance zones
3. **Circular Constraint**: Triangle inequality holds on the circle
4. **Impossibility**: Cannot arrange 16 frequencies to avoid both blue K₅ and red K₅

### The Impossible Triangle

The right panel shows a configuration that cannot exist:
- Two red edges (AB, AC): both pairs non-resonant
- One blue edge (BC): this pair resonant

But circular triangle inequality requires:
```
d(A,B) + d(B,C) ≥ d(A,C)
```

For small ε relative to f₀, this creates contradictions that force monochromatic cliques.
