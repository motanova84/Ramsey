## Encoding Details

### Variables

1. **Frequency Variables** (one-hot encoding):
   - `k[i][j]` = vertex i has frequency j×(f₀/grid)
   - i ∈ [0, n), j ∈ [0, grid)
   - Total: n × grid = 16 × 128 = 2,048 variables

2. **Edge Color Variables**:
   - `edge[i][j]` = 1 if edge (i,j) is blue (resonant)
   - i < j, i,j ∈ [0, n)
   - Total: n(n-1)/2 = 120 variables

3. **Auxiliary Variables** (Tseytin encoding):
   - For complex boolean formulas
   - Total: ~15,360 variables

### Constraints

1. **One-hot encoding**: Each vertex has exactly one frequency
   - Clauses: n × (grid + C(grid,2)) ≈ 131,200

2. **Edge coloring**: Define edge colors based on frequency distance
   - Clauses: ~40,000

3. **Ramsey constraints**:
   - Forbid all-blue K₅: C(16,5) = 4,368 clauses
   - Forbid all-red K₅: C(16,5) × 10 ≈ 43,680 clauses (expanded)

4. **Symmetry breaking** (optional):
   - Fix ordering of first few vertices
   - Clauses: ~100
