USAGE EXAMPLES
════════════════════════════════════════════════════════════════════════════════

1. Generate CNF Instance:
   ─────────────────────────────────────────────────────────────────────────
   $ cd rpsi-proof/src
   $ python3 generate_instance.py
   
   Output: ../data/coloring_r16.cnf (17,528 variables, 200,360 clauses)

2. Solve and Generate LRAT Certificate:
   ─────────────────────────────────────────────────────────────────────────
   $ kissat --unsat --lrat=../cert/proof_r16.lrat ../data/coloring_r16.cnf
   
   Output: s UNSATISFIABLE (proof in ../cert/proof_r16.lrat)

3. Verify LRAT Certificate:
   ─────────────────────────────────────────────────────────────────────────
   $ python3 verify_lrat.py ../data/coloring_r16.cnf ../cert/proof_r16.lrat
   
   Output: ✅ CERTIFICADO LRAT VÁLIDO

4. Run Unit Tests:
   ─────────────────────────────────────────────────────────────────────────
   $ python3 test_rpsi_scripts.py -v
   
   Output: 4 tests passed ✅
