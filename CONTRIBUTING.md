# CONTRIBUCIONES

## Cómo Contribuir

¡Las contribuciones son bienvenidas! Este proyecto implementa una teoría matemática innovadora que combina rigor técnico con visión transformadora.

### Áreas de Contribución

1. **Mejoras Algorítmicas**
   - Optimización del solver SAT para grafos grandes
   - Algoritmos más eficientes para detección de cliques
   - Mejoras en la estimación de conjeturas

2. **Verificación Teórica**
   - Demostración formal de conjeturas
   - Casos de prueba adicionales
   - Análisis de límites asintóticos

3. **Aplicaciones Prácticas**
   - Análisis de redes reales
   - Nuevos casos de uso
   - Integración con frameworks existentes

4. **Visualización**
   - Gráficos interactivos
   - Animaciones de resonancia
   - Dashboards de análisis

5. **Documentación**
   - Tutoriales adicionales
   - Traducciones
   - Ejemplos de casos de uso

### Proceso de Contribución

1. Fork el repositorio
2. Crea una rama para tu feature: `git checkout -b feature/nueva-funcionalidad`
3. Realiza tus cambios siguiendo el estilo del código existente
4. Agrega tests para nuevas funcionalidades
5. Ejecuta los tests: `python test_ramsey.py`
6. Commit tus cambios: `git commit -m "Descripción clara"`
7. Push a tu fork: `git push origin feature/nueva-funcionalidad`
8. Abre un Pull Request

### Estándares de Código

- Python 3.8+
- Docstrings en español para funciones principales
- Type hints cuando sea posible
- Tests unitarios para nuevas funcionalidades
- Código limpio y bien comentado

### Tests

Antes de enviar un PR, asegúrate de que todos los tests pasen:

```bash
python test_ramsey.py
```

### Reportar Issues

Si encuentras un bug o tienes una sugerencia:

1. Verifica que no exista un issue similar
2. Abre un nuevo issue con:
   - Descripción clara del problema o sugerencia
   - Pasos para reproducir (si es un bug)
   - Comportamiento esperado vs. actual
   - Versión de Python y dependencias

## Código de Conducta
